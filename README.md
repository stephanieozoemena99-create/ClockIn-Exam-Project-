# ClockIn

A digital attendance register for recording students present during a lecture.

Built for the EMCICT311 Mini Project examination, assigned Topic 8 (Attendance Register).

## What it does

The lecturer types in student names, marks each one present or absent with a button,
and ClockIn counts them and remembers everything even after the browser is closed.

| Feature | Marks |
| --- | --- |
| Add student names | 3 |
| Mark Present / Absent | 6 |
| Display attendance list | 3 |
| Count total present | 3 |
| Count total absent | 3 |
| Search student names | 3 |
| Save attendance using Local Storage | 6 |
| Edit attendance record | 3 |

## How to run it

Download or clone this repository, then open `index.html` in any web browser.

There is nothing to install. No server, no internet connection required.

## Built with

HTML, CSS and plain JavaScript. No frameworks and no build step.

## Project structure

    index.html        the page structure
    css/styles.css    every colour, size and space
    js/student.js     the Student class
    js/register.js    all the rules
    js/storage.js     saving to and loading from Local Storage
    js/app.js         listens for clicks, redraws the screen
